    How real bots plug in

    Each bot sends a small event when it changes what it's doing. The town only reads these, so it costs no tokens.

    POST /api/event
{ "bot": "Nova",
  "state": "working",
  "task": "Sketching the onboarding flow" }
    • first event → light beam on Summon Hill
    • working → walks into its workplace
    • quiet → time off: benches and skipping stones in the park, the plaza, the library by day, a drink inside the pub (afternoon and evening)
    • quiet Researchers → read in the library by day
    • quiet at night → home to bed, 5 bots per house
